# 🎬 Automated Script & Storyboard Breakdown Agent

An AI-powered pre-production assistant built with **Streamlit** and the **Google Gemini API**. This agent automates screenplay breakdowns and generates structured visual storyboard prompts to eliminate manual administrative overhead for filmmakers.

---

## 🚀 Features

* **Automated Screenplay Analysis:** Extracts characters, props, costumes, locations, and special effects from raw script scenes in seconds.
* **AI Storyboard Prompt Generation:** Automatically creates detailed, shot-by-shot visual prompts optimized for AI image generators.
* **Pipeline-Ready Export:** Export clean, structured scene metadata as JSON for direct integration into budgeting, scheduling, and production software.
* **Interactive Dashboard:** Clean visual interface built with Streamlit for quick scene inspection and data verification.

---

## 🛠️ Tech Stack

* **Language:** Python
* **Frontend:** Streamlit
* **Core AI:** Google Gemini API (`google-generativeai`)
* **Data Processing:** JSON / Standard Library
